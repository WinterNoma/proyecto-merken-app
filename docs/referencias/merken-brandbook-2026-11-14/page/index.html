01 / Brand essence

Authority through clarity.

Mission

Make locally available health observations understandable: what was recorded, what the core evaluated, what remains unknown and what action is available.

Personality

Institutional. Technical. Restrained. Accountable. The structure of a technical manual, with the immediacy of an operational console.

  1. Evidence before interpretation.
  2. Make uncertainty legible.
  3. Reserve emphasis for consequence.
  4. Support deliberate action.
  5. Remain useful offline.

02 / Wordmark

One word. One signature.

Barlow Semi Condensed 600 · uppercase · 0.06em tracking · no symbol

Horizontal / pale ink on graphite

Minimum visible word width: 112 px. SVG masters contain editable text and name the required font; they are not outlined. The mark stays fixed while interface type is compared below.

03 / Color

Quiet surfaces. Explicit meaning.

Three complete dark palettes. Choose one to preview it across this document. Semantic colors remain fixed.

Shared semantic colors

Color always travels with an icon and text. No data and stale readings are neutral conditions, not health alarms. Blue denotes an action or focus.

Contrast method and full pair matrix

Opaque sRGB, WCAG relative luminance. Text target 4.5:1; essential borders and focus 3:1. Ratios are displayed to two decimals; results use unrounded values. The matrix checks all general surfaces and button states. Decorative dividers are excluded.

This validates the listed color pairs, not complete WCAG conformance or physical low-light performance.

Figure discipline

Use tabular lining figures. Align comparable values to the right. Preserve recorded precision. Keep units visible. Show UTC on timestamps and distinguish measurement time from sync time.

06 / Voice & tone

Calm. Precise. Accountable.

State the observation, its limitation and the available action. No diagnostic labels, invented reassurance, humor or medical advice.

Three independent facts

Stable describes an evaluation. Saved locally describes persistence. Synchronized describes a record's sync status. None proves that a person on ground has reviewed it.
