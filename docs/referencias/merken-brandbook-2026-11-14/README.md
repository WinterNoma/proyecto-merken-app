# MERKEN — Brand standard 01 (14 November 2026)

Approved direction: **B / Basalt Standard** palette + **Flight Documentation** type
(Barlow Semi Condensed / Public Sans / Roboto Mono, all SIL OFL 1.1).

| File | What it is |
|---|---|
| `brandbook.md` | Full brand standard: essence, voice and tone (ready-to-use copy), wordmark, color, type, tokens and components |
| `tokens.css` | CSS custom properties (`--mk-*`). `:root` defaults = approved Basalt palette; alternatives commented |
| `logo/` | Wordmark SVGs (editable text; needs Barlow Semi Condensed 600 installed to render exactly) |
| `page/index.html` | Visual brand page with live specimens. Open in a browser (works offline, fonts included) |

Fonts: https://fontsource.org (npm `@fontsource/barlow-semi-condensed`, `@fontsource/public-sans`, `@fontsource/roboto-mono`) or Google Fonts.
