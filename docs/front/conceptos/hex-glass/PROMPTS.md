# Exploracion visual PULSYS: Hex + vidrio esmerilado

Referencias: captura de usuario (vidrio esmerilado y roca oscura), interfaz general de Hex y capsula flotante de captura de Hex. Las referencias de Hex se encuentran en ../../referencias/hex/.
