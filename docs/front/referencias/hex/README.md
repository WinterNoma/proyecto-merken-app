# Referencias visuales de Hex

Capturas oficiales de pruebas visuales publicadas en [anomalyco/hex](https://github.com/anomalyco/hex), descargadas como referencia para Merken. No son capturas nuevas de una instalacion local.

Revision: `31feb6f0e8569700faea46ac54db083a535602cd`.

- `00-panel-referencias.jpg`: hoja de contacto; los PNG conservan los originales completos.
- `01-interfaz-general.png`: superficies, navegacion, tipografia y filas de ajustes.
- `02-historial.png`: composicion del historial.
- `03-hud-lab.png`: panel de configuracion del HUD de dictado; el indicador flotante vive en una ventana separada y no aparece en esta captura.
- `04` a `08`: capsula flotante del flujo de captura de pantalla/grabacion, con estados de grabacion, procesamiento, resultado, destino y tema claro. No confundirla con el indicador de dictado de puntos (Dot scope).

`fuentes.json` contiene los enlaces fijados a la revision exacta. `LICENSE-hex.txt` conserva la licencia del repositorio fuente.

Las referencias se guardaron para explorar la direccion visual; no se modifico el frontend de Merken.
